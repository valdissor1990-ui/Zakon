# ЗаконЪ

Автономный юридический помощник по законодательству Российской Федерации для Android.

## Структура репозитория

- `app/` — Android-клиент на Kotlin и Jetpack Compose.
- `content/` — схема SQLite, реестр источников и версии правовой базы.
- `agent/` — проверка происхождения данных и подготовка выпусков контента.
- `docs/` — архитектура, требования к достоверности и правила сверки источников.
- `.github/workflows/` — автоматические проверки и сборка APK.

## Реализовано в текущем каркасе

- Экран каталога документов.
- Экран документа со списком статей.
- Экран чтения статьи с вертикальной прокруткой.
- Поиск по локальной базе с FTS4 и резервным поиском по тексту.
- Навигация по экранам и возврат системной кнопкой Android.
- SQLite-слой для локальных документов и статей.
- Автоматическая проверка схемы базы и реестра источников.
- GitHub Actions для сборки debug APK.

## Что ещё не готово

Правовая база пока не наполнена проверенными текстами. Сейчас приложение покажет пустое состояние, а не выдуманные нормы. Импорт базы, безопасное обновление контента, карточки источников, перекрёстные ссылки и юридические инструменты будут добавляться следующими этапами.

## Источники законодательства

В `content/sources/registry.json` зарегистрированы три государственные точки сверки: официальный портал опубликования, интегрированный банк «Законодательство России» и портал НПА Минюста. Правила использования и блокировки публикации при расхождениях описаны в `docs/SOURCE_POLICY.md`.

## Сборка

Для локальной сборки требуется Android Studio с JDK 17 и Android SDK 36. Откройте репозиторий в Android Studio и запустите задачу `assembleDebug`.

GitHub Actions публикует APK как артефакт успешного запуска workflow, а не как готовый релиз. Подписанный Release APK и механизм обновления будут настроены отдельно после добавления защищённого ключа подписи через GitHub Secrets.

## Принципы достоверности и приватности

1. Текст нормы не генерируется и не восстанавливается по догадке.
2. Для каждого документа сохраняются источники, реквизиты редакции, даты получения и контрольные суммы.
3. При расхождении источников выпуск блокируется до ручной проверки.
4. Дата принятия, официального опубликования и вступления в силу хранятся раздельно.
5. Чтение и поиск после установки базы должны работать без интернета.
6. Пользовательские данные остаются на устройстве.
7. Секреты подписи и токены не коммитятся в репозиторий.
