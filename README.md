# ЗаконЪ

Автономный юридический помощник по законодательству Российской Федерации для Android.

## Структура

- `app/` — Android-клиент на Kotlin и Jetpack Compose.
- `content/` — схема и версии локальной правовой базы, метаданные источников и индексы.
- `agent/` — инструменты сбора, сверки, проверки и подготовки выпусков контента.
- `docs/` — архитектура, правила качества и инструкции.

## Принципы достоверности

1. Текст нормы не генерируется и не восстанавливается по догадке.
2. У каждой публикации должны быть источник, дата получения, реквизиты редакции и контрольная сумма.
3. Статус документа и дата действия нормы хранятся отдельно от текста.
4. Не прошедшие проверки материалы не попадают в опубликованный выпуск.
5. Пользовательские данные остаются на устройстве. Сеть используется только для проверки и загрузки обновлений.

## Состояние проекта

Начальная структура проекта. Полнота правовой базы и работоспособность релизной сборки будут подтверждаться отдельными проверками и отчётами.

## Сборка

Откройте репозиторий в Android Studio и дождитесь синхронизации Gradle. Для локальной сборки используйте задачу `assembleDebug`.
