# ЗаконЪ

Автономный юридический справочник по законодательству Российской Федерации для Android.

## Независимые версии

Android APK и правовая база выпускаются отдельно:
- app/ — приложение, интерфейс, навигация, поиск и менеджер контента;
- content/ — схема, источники, записи и манифесты правовой базы;
- agent/ — проверка и сборка SQLite;
- docs/ — архитектура, безопасность и правила достоверности.

Юридические тексты не должны включаться в APK. На новой установке приложение создаёт пустую локальную базу и загружает отдельный SQLite-выпуск. После загрузки поиск и чтение работают офлайн. При обновлении контента APK не меняется.

## Локальное хранение

- zakon-content.db — правовая база.
- Старый zakon-local.db при обновлении копируется в новое хранилище, если оно ещё не существует; исходный файл сохраняется.
- Пользовательские дела и документы кабинета остаются в отдельном хранилище и не затрагиваются обновлениями законодательства.

## Обновление контента

Клиент получает content/updates/manifest.json. При совпадении базовой версии он применяет небольшой delta-пакет транзакционно; иначе скачивает полный SQLite-файл. Оба пути доступны только из манифеста с действительной подписью RSA/SHA-256 и статусом validated; пакеты проверяются по SHA-256. Полный файл дополнительно проходит проверку SQLite и атомарную установку с резервным восстановлением. Удалённые JSON-пакеты не принимаются. Импорт JSON с устройства остаётся отдельной ручной функцией.

Полный формат выпуска описан в content/manifest.example.json и docs/ARCHITECTURE.md.

## Наполнение базы

Агент собирает SQLite только из проверенных структурированных записей. Каталог первой очереди — `content/catalog/core-federal-acts.json` — содержит 16 фундаментальных федеральных актов, но пока только реквизиты и поисковые задания, не тексты законов. Для каждого документа требуются оригиналы из трёх разных государственных информационных систем, представляющих минимум двух операторов, совпадение редакций и ручное подтверждение. Агент не генерирует и не дополняет тексты норм.

В репозитории пока нет полного проверенного content/records/records.json, поэтому полноценная база законодательства ещё не опубликована. Не следует считать демонстрационный JSON-пакет полноценной или официальной правовой базой.

## CI и публикация

- content-check.yml — проверка схемы, источников и тестов.
- content-release.yml — ручная публикация отдельного Content Release после approval.
- android-build.yml — независимая сборка APK, unit-тесты и миграционные instrumentation-тесты на эмуляторе Android 8.0 (API 26).

Перед использованием release workflow необходимо:
- настроить GitHub Environment `legal-content-approval` с обязательными проверяющими;
- добавить секрет `LEGAL_CONTENT_SIGNING_PRIVATE_KEY` в Settings → Secrets and variables → Actions. Приватный ключ нельзя коммитить в репозиторий.

## Сборка Android

Требуется Android Studio с JDK 17 и Android SDK 36. Минимальная версия Android — API 26.

Откройте репозиторий в Android Studio и запустите assembleDebug. GitHub Actions выполняет тесты, lint и сборку debug APK.
