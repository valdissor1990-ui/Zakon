# Агент подготовки правовой базы

Агент предназначен для воспроизводимого процесса: получение документов из официальных источников, сохранение исходных копий и реквизитов, нормализация структуры, межисточниковая сверка, валидация и подготовка выпуска.

## Жёсткие правила

- Не генерировать отсутствующий текст нормы.
- Не считать совпадение заголовков доказательством совпадения редакций.
- Сохранять URL, время получения, реквизиты публикации и SHA-256 исходного файла.
- Различать дату принятия, официального опубликования и вступления в силу.
- При расхождении источников отправлять документ на ручную проверку.
- Не публиковать выпуск при ошибках целостности или неполной проверке.

`capture_sources.py` сохраняет исходные файлы по URL из подготовленных records.json. Он принимает только HTTPS-хосты из registry.json, проверяет хост каждого перенаправления, ограничивает размер файла и записывает SHA-256 и метаданные получения. Скрипт не распознаёт HTML/PDF, не извлекает нормы и не меняет records.json: юридическое структурирование и сверка выполняются отдельно человеком. Специализированные адаптеры под конкретные форматы источников потребуют самостоятельных тестов и контроля актуальности.


## Несколько документов из одного портала

Для каждого документа сохраняется отдельная запись в `records.sources`. Поле `registry_id` ссылается на один из разрешённых порталов в `content/sources/registry.json`, а уникальное поле `key` задаёт каталог доказательств конкретного захвата. Например: `key=koap__pravo_bank`, `registry_id=pravo_law_bank`. Это позволяет хранить отдельные редакции и исходные файлы одного портала для разных нормативных актов, не смешивая доказательства.

Каталог `content/catalog/core-federal-acts.json` содержит приоритетный перечень федеральных актов. Его записи — только очередь подготовки: статус `not_imported` означает, что текста в базе нет. Каталог не подменяет документы и не считается источником правовой нормы.
