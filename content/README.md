# Правовая база

Каталог предназначен для версионируемых выпусков автономной правовой базы.

## Формат выпуска

Каждый выпуск должен содержать:
- SQLite-базу;
- manifest.json с номером версии, датой формирования и контрольной суммой;
- реестр источников и даты получения;
- отчёт автоматических проверок.

Не добавляйте сюда непроверенные или синтетически восстановленные тексты законов. Большие бинарные выпуски планируется публиковать в GitHub Releases, а в Git хранить схему, манифесты и служебные файлы.
