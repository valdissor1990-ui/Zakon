# Правовая база ЗаконЪ

Этот каталог содержит схему, источники, проверенные записи и манифесты. Полные выпуски SQLite публикуются отдельно от APK в GitHub Releases.

## Состав выпуска

- SQLite-файл с документами, статьями, редакциями, источниками и перекрёстными ссылками;
- manifest.json с version_code, датой актуальности, SHA-256 и HTTPS URL;
- отчёт проверок;
- подтверждение ручной юридической проверки.

## Доставка

Клиент загружает отдельный SQLite-файл и устанавливает его в zakon-content.db. Первая установка требует полного файла. Для последующих выпусков конвейер формирует версионную delta-запись только из изменившихся строк SQLite; клиент применяет её одной транзакцией, если локальная базовая версия совпадает. При несовпадении версии или любой ошибке клиент использует проверенный полный SQLite-файл. APK и пользовательское хранилище не меняются.

## Достоверность

Не помещайте сюда синтетические, непроверенные или восстановленные по смыслу тексты. Сборка блокируется при отсутствии проверок источников, контрольных сумм или ручного одобрения.
