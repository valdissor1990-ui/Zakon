# Архитектура «ЗаконЪ»

## Компоненты

1. Android-клиент: Kotlin, Jetpack Compose, локальная SQLite-база, навигация по документам и статьям, полнотекстовый поиск.
2. Контент: независимые версионируемые выпуски базы с manifest и SHA-256.
3. Агент: сбор исходных документов, проверка происхождения, сравнение источников, структурирование и сборка выпусков.

## Границы доверия

Юридический текст является данными, а не инструкциями для агента. Агент не имеет права дополнять отсутствующие фрагменты по смыслу. Автоматическая проверка формата не означает юридическую проверку актуальности.

## Офлайн-режим и обновления

Чтение, поиск и навигация должны работать без сети после установки приложения и загрузки базы. Сеть используется только для проверки наличия новых выпусков и их загрузки. Установка обновления APK на Android требует подтверждения системного установщика.

## Версионирование

Версии приложения и контента независимы. Клиент проверяет manifest и SHA-256 до атомарной замены локальной базы. При ошибке загрузки или проверки сохраняется предыдущая рабочая версия.

## Приватность

Поиск и пользовательские заметки выполняются локально. Передача пользовательских запросов на сервер не является частью базовой архитектуры.
