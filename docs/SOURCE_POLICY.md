# Правила выбора и сверки источников

## Реестр источников

Список источников находится в `content/sources/registry.json`.

1. **Официальное опубликование** — Официальный интернет-портал правовой информации. Используется для исходного опубликованного текста, даты публикации и актов о внесении изменений.
2. **Интегрированный банк «Законодательство России»** — государственный полнотекстовый банк. Для видов актов, прямо охваченных описанием портала, тексты имеют официальный статус.
3. **Портал Минюста** — государственная система НПА, используемая как дополнительная контрольная точка для реквизитов, систематизированного текста и регистрационных сведений.

## Правило приоритета

Эти источники не взаимозаменяемы. Официальная публикация и официальная консолидированная редакция имеют разное назначение. Портал Минюста используется для дополнительной сверки, но не подменяет источник официального опубликования.

Первые два ресурса относятся к государственной системе правовой информации, третий — к Минюсту. Поэтому это три разные информационные системы, но не три полностью независимых оператора. Реестр явно хранит `system_id` и `operator_id`; контроль требует не менее трёх систем и двух операторов. Это честнее, чем объявлять разные разделы одного портала полностью независимыми источниками.

Для каждого документа сохраняются:
- исходный URL и дата получения;
- реквизиты акта и редакции;
- контрольная сумма оригинального файла;
- дата принятия, опубликования и вступления в силу (если применимо);
- результат сверки каждого источника.

## Блокировка выпуска

- Не удалось получить один из трёх государственных информационных систем — ручная проверка.
- Отличается текст, редакция, дата или реквизит — публикация блокируется.
- Нет надёжного подтверждения вступления нормы в силу — статус не назначается автоматически.
- Запрещено дописывать или восстанавливать пропущенные положения по смыслу.

Официальный портал может требовать JavaScript или быть временно недоступен. Сборщик должен использовать сохранённые исходные копии, повторять запросы с ограничением частоты и журналировать ошибки. Недоступность источника не означает, что текст можно заменить данными из неофициальной справочной системы.


## Каталог и редакции

Для первичного охвата используется каталог `content/catalog/core-federal-acts.json`. Он фиксирует только наименование, реквизиты для поиска и приоритет. Он не подтверждает действительность акта и не содержит нормативного текста. Для каждого акта отдельно сохраняются исходные публикации/редакции каждого портала, дата получения, идентификатор редакции и SHA-256. Сверка должна сопоставлять не только заголовки, но и полный текст, редакцию и даты действия норм.
